## I made a free DIY board game collection + play tracker

Game Vault is an installable web app powered by a Google Sheet you own. It tracks your collection and plays, picks a game for the table, keeps head-to-head stats, and can fill public game metadata from BoardGameGeek.

You do not need to know how to code. The starter pack includes a Sheet template and a click-by-click setup guide.

- Try the sample demo: https://jseggs.github.io/game-vault-PWA/community/
- Get the template and guide: [add release or repository link]
- Cost: free and open source

Privacy note: the demo contains only sample data. Your connection URLs and write key stay in your browser. The optional Google script is bound to your copied tracker and asks only for access to that Sheet plus permission to retrieve BGG metadata. Publishing Sheet tabs as CSV makes those selected tabs public, so the guide explains exactly what should and should not be published.

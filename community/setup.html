Game Vault Community Edition

Build your own game tracker.

No coding experience needed. Follow these steps to connect the app to a Google Sheet you own.

Download the Sheet template Download complete starter kit Open the sample app
Plan for 25–40 minutes. Keep the sample rows until everything connects. You can replace them with your games at the end.
1

Turn the template into a Google Sheet

  1. Download the template above.
  2. Open Google Drive and choose New → File upload.
  3. Upload the workbook, then right-click it and choose Open with → Google Sheets.
  4. If an .xlsx label remains, choose File → Save as Google Sheets.
  5. In the Players tab, replace Player 1 and Player 2 with the names or nicknames you want in the app.

Keep the tab names Games, Plays, Stats, and Players exactly as written.

2

Add the connector

  1. In the Sheet choose Extensions → Apps Script.
  2. Replace the contents of Code.gs with the packaged Code.gs.
  3. Add a new Script file named BGG and paste the packaged BGG.gs.
  4. In Project Settings, turn on Show appsscript.json manifest file.
  5. Replace that manifest with the packaged appsscript.json, then save.
  6. Reload the Sheet. A Game Vault menu appears.
3

Approve only the permissions it needs

Current spreadsheet onlyThe connector can edit this tracker. It cannot browse all the spreadsheets in your Drive.
External requestsThe optional BGG button can send only a game title or BGG ID to the public lookup service.

It does not request Gmail, Contacts, Calendar, or broad Drive access. A copied script may still show Google's unverified-app warning. Continue only if the two permissions above are the complete list and your files exactly match this package.

4

Copy your private write key

  1. In the Sheet choose Game Vault → Show connection key.
  2. Approve the two permissions if asked.
  3. Choose Copy key and keep it private.

The random key is stored in the script's private settings. Never place it in a Sheet cell or public post.

5

Deploy the connector

  1. In Apps Script choose Deploy → New deployment → Web app.
  2. Set Execute as to Me.
  3. Set Who has access to Anyone.
  4. Deploy and copy the URL ending in /exec.

The public endpoint cannot write without the private key. It is bound to this one tracker Sheet.

6

Publish four read-only CSV links

  1. In the Sheet choose File → Share → Publish to web.
  2. Choose the Games tab, then Comma-separated values (.csv). Publish and copy the URL.
  3. Repeat for Plays, Stats, and Players.

Never publish Entire document, START HERE, or Lists. Published CSV tabs are public to anyone with their long URL, so keep sensitive information out of them.

7

Connect Game Vault

  1. Open the Community Edition app and choose Settings.
  2. Paste the four CSV URLs into their matching fields.
  3. Paste the Apps Script /exec URL and private write key.
  4. Choose Save & Sync.

Connection values remain in this browser. Repeat this step on each device where you install the app.

8

Add your games and install the app

  1. Replace sample rows in Games. Keep the header row.
  2. For BGG details, select a game row and choose Game Vault → Enrich selected game from BGG.
  3. Delete the sample rows in Plays.
  4. On iPhone use Safari → Share → Add to Home Screen. On Android or desktop use the browser's Install command.

That’s it. Your Sheet is the database.

Collection browsing, game picking, play logging, ratings, stats, player dinosaurs, and offline installation all remain available. The old Ready to Play column and global filter are intentionally not part of this edition.
